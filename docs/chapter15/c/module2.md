## 核心内容

### 1. 后训练：激发预训练的潜能

#### 1.1 三种后训练方法速览

Module 1 的结论是：预训练模型已经蕴含推理能力。那后训练在做什么？

| 方法 | 做什么 | 数据来源 | 关键特点 |
|------|--------|---------|---------|
| **SFT（监督微调）** | 在高质量 (prompt, answer) 对上做监督学习 | 人工标注 / 强模型生成 | 让模型学会"按人类期望的格式输出" |
| **RL（强化学习）** | 通过奖励信号优化模型输出的分布 | 模型自身探索 + 奖励函数 | 重分配概率，让正确路径更容易被采样（Module 1 Pass@k 结论） |
| **蒸馏（Distillation）** | 用强模型（teacher）的输出来训练弱模型（student） | Teacher 模型生成 | 可以**注入外部知识**（突破 student 自身能力上限），而不仅是重分配 |

> 📎 **与第 13-14 章的关联**：第 13 章 Module 3-5 详细讲解了 SFT → RLHF → DPO 的技术细节，第 14 章讲解了 GRPO/RLVR。本模块不再重复这些技术的公式和算法，而是聚焦于一个更高层的问题——**这些后训练方法到底改变了模型的什么？是"教新能力"还是"唤醒已有能力"？**

#### 1.2 后训练的本质：激发与对齐

课程原文引用了一个关键结论（综合 Yue et al. 2025、李飞飞团队 s1 研究、DeepSeek-R1 报告）：

> 后训练本质上是对预训练阶段所积累潜能的"激发"与"对齐"。预训练构筑了模型能力的基石，而后训练是让这些内化的能力以更符合人类预期或逻辑规范的方式展现出来。

两条关键证据线：

**证据 1：基座模型规模决定 RL 收益上限**

Mind Lab 2025 年的研究使用 LoRA 对不同规模的模型进行 RL 后训练，发现：更大/更强的基座模型 → RL 收益更大。解释：RL 依赖基座模型提供足够好的策略初始化（先验能力）——如果基座模型本身能力不足，RL 难以在其基础上探索到更合理的推理轨迹。

```
小基座模型 + RL → 有限的提升（参数空间中没有足够好的推理路径）
大基座模型 + RL → 显著的提升（参数空间中已有正确路径，RL 提高其概率）
```

**证据 2：蒸馏可以突破 student 模型自身的能力边界**

DeepSeek-R1 报告中的一个关键发现：将 R1 的推理能力蒸馏到较小模型后，小模型的表现**优于**对其直接进行 RL 训练。

这与纯 RL 的逻辑不同：
- RL：依赖模型**自己的探索** → 受限于预训练积累的能力上限
- 蒸馏：引入 teacher 模型的**外部知识和推理模式** → 为 student 注入其预训练阶段未覆盖的信息

> ⚠️ **但蒸馏也有天花板**：student 模型需要具备足够的容量（表征能力）才能"接住" teacher 的知识。蒸馏不是魔法——它的上限受 student 模型参数量和预训练质量的制约。

#### 1.3 RL 中的奖励欺骗（Reward Hacking）与 KL 约束

在后训练 RL 过程中，如果使用 AI 验证器（奖励模型）为模型输出提供奖励信号，可能出现**奖励欺骗**——模型学会利用奖励模型的漏洞获取高奖励，而非真正提升输出质量。

缓解方法：在优化目标中引入 **KL 散度惩罚项**，约束微调后的策略分布 π_θ 与原始参考策略分布 π_ref 之间的偏离程度：

$$J(\theta) = \mathbb{E} [R(x, y)] - \beta \cdot D_{KL}(\pi_\theta \parallel \pi_\text{ref})$$

其中 β 控制约束强度。这在第 13 章 Module 4（RLHF/PPO）和第 14 章 Module 2（Dr.GRPO 的 KL 正则化）中都有详细展开。

### 2. CoT：思维链越长越好吗？

#### 2.1 倒 U 型曲线

CoT（Chain-of-Thought）由 Google Research 在 2022 年提出——通过让模型显式生成中间推理步骤，显著提升复杂推理任务的表现。但后续研究揭示了一个反直觉的发现：

> 🌐 **补充（Peking University, arxiv 2502.07266）**：北大团队通过控制实验构造了不同长度的推理链，在多个难度梯度的任务上绘制出长度-准确率曲线。结果发现 **CoT 长度与准确率之间呈现倒 U 型关系**——在一定范围内，随着 CoT 长度增加，准确率提升；超过最优长度后，准确率反而下降。

<p>图：(a) GPT2 在不同难度算术任务上的倒 U 型表现，难度越高最优 CoT 长度越长；(b) Qwen2.5-7B GRPO 训练过程中，准确率提升但过长 CoT 仍导致性能下降</p>

**为什么会下降？** 课程原文给出了合理解释：
- CoT 本质上是 LLM 解题的"草稿纸"
- 适度延长推理步骤使模型能自我验证与修正，提升自洽性
- 但过长的推理链受限于 **Transformer 的有限上下文窗口**——长距离依赖下注意力被不断稀释，关键信息逐渐被遗忘
- 模型陷入"反复修改却无法收敛"的恶性循环 → 错误率上升

**最优 CoT 长度随任务难度变化**：从图 (a) 可以看出，更难的算术任务（如 4 位数加法 vs 2 位数加法）的倒 U 峰值出现在更长的 CoT 长度上——越难的问题需要越长的"草稿"。

#### 2.2 推理长度 ≠ 推理深度

倒 U 型曲线引出了一个关键区分：一条 1000 token 的 CoT 中，可能只有 200 token 在真正"思考"，剩下 800 token 是语法填充词和模板化表达。如何量化？

### 3. DTR（Deep Thinking Ratio）— 2W2H

#### What（是什么）

**DTR（Deep Thinking Ratio）** 是 Google Research 团队在 2026 年论文 *"Think Deep, Not Just Long"*（[arxiv 2602.13517](https://arxiv.org/abs/2602.13517)）中提出的推理度量指标：

$$\text{DTR} = \frac{\text{Deep-Thinking Token 数量}}{\text{总生成 Token 数量}}$$

其中 **Deep-Thinking Token** 的定义是：在 Transformer 各层对该 token 的预测分布中，如果预测在**较深层网络中仍持续发生明显变化**（直到后期层才趋于稳定），该 token 被标记为 Deep-Thinking Token。反之，如果在浅层网络中就基本稳定，则为**浅层 token**。

#### Why（为什么需要它）

DTR 试图回答一个问题：**LLM 在推理时到底是在"努力思考"，还是在"凑字数"？**

传统的 CoT 长度指标只衡量了"输出量"，而 DTR 衡量的是"计算深度"。从倒 U 型曲线可以看到，更长的 CoT ≠ 更好的表现，但之前的工具无法解释**为什么**——DTR 提供了原因：长 CoT 中可能混入了大量浅层 token。

#### How（怎么计算）

具体机制：研究者通过分析 **Transformer 各层对同一 token 的预测分布变化**（使用 Jensen-Shannon 散度衡量相邻层之间预测分布的差异）来判断该 token 的"收敛层"：

1. 逐层记录模型在每个位置上的预测分布
2. 计算相邻层预测分布的 JS 散度
3. 如果 JS 散度在浅层（如前 6 层）已趋于 0 → **浅层 token**（模型很早就"知道"该输出什么）
4. 如果 JS 散度在深层（如 20+ 层）才趋于 0 → **Deep-Thinking Token**（模型需要深层计算才能确定）

#### How much（边界与使用限制）

DTR 的核心发现：

> 🌐 **补充（Web Search / Google Research, 2026）**：实验表明 DTR 与模型准确率呈**明显正相关**，且利用 DTR 指导推理可以**将推理成本减半同时保持准确率**。关键在于——不是所有 token 都需要"深度思考"，DTR 可以帮助识别哪些 token 真正受益于深层计算。

**DTR 的定位与局限**：
- DTR 是一个**统计性指标**，不是因果度量。浅层 token 和深层 token 共同构成完整推理结构（浅层负责语言组织，深层负责关键推断），不能简单说"浅层 token 无用"
- DTR 目前是**分析工具**而非训练目标——尚未有工作直接将 DTR 作为优化目标进行 RL 训练
- 如果未来要在 CoT 优化中应用 DTR，可能需要结合注意力分布、token 不确定性、推理路径一致性等多维度信息，综合评估 CoT 的"有效长度"

**DTR 揭示的核心区分**：

```
推理长度 ≠ 推理深度

长 CoT（1000 token）   ──→  DTR 可能只有 15%（150 token 在深层思考）
短 CoT（300 token）    ──→  DTR 可能高达 40%（120 token 在深层思考）
                                        ↑
                            后者的"有效推理"可能比前者更多
```

<summary>📖 Q1 参考答案</summary>

**(a) RL 是"激发"而非"创造"**：

证据来自 Module 1 的 Pass@k 分析（Yue et al., 2025）：
- k 小（k=1）：RLVR 模型准确率明显更高 → RL 让正确路径更容易被采样到
- k 大（k=100）：基座模型准确率逼近甚至反超 RLVR 模型 → 正确路径在基座模型中**本就存在**

这说明 RL 没有为模型注入参数空间中不存在的新能力。它的机制是**概率重分配**（probability redistribution）：通过优势函数 A_t，增加正确推理路径上 token 的概率，降低错误路径的概率。GRPO/PPO 的微观机制（第 14 章）和 Pass@k 的宏观证据相互印证。

证据 1 从另一个角度强化了这个结论——基座模型越大，RL 收益越大。因为大模型参数空间中的正确路径更多、更完整，RL 有"东西可激发"；小模型参数空间中可能根本没有好的推理路径，RL 无从激发。

**(b) 蒸馏可以突破 student 能力边界，但有天花板**：

**为什么能突破**：蒸馏与 RL 的本质区别在于数据来源：
- RL：模型**自己探索** → 受限于预训练积累的分布空间 → 无法产生自己参数空间中不存在的推理模式
- 蒸馏：teacher 模型生成训练数据 → 包含 teacher 的推理策略和知识 → 这些可能不在 student 的预训练分布中

DeepSeek-R1 报告验证了这一点：将 R1 的推理能力蒸馏到小模型，效果**优于**直接对小模型做 RL 训练。

**天花板在哪**：student 模型的参数量和预训练质量。蒸馏不是魔法——teacher 输出的信息需要 student 有足够的表征能力才能"接住"。一个 0.5B 的模型即使被 GPT-5 蒸馏，也不会突然拥有 GPT-5 级别的推理能力。容量的硬上限 + 预训练分布的范围 = 蒸馏的软上限。

<summary>📖 Q2 参考答案</summary>

**倒 U 型的含义**：CoT 充当 LLM 解题的"草稿纸"。在一定范围内，增加推理步数使模型能够进行自我验证、中间纠错和逻辑推演，准确率随之上升。但超过最优长度后，继续增加 CoT 反而降低准确率。

**Transformer 架构角度的下降原因**（三条机制）：

1. **注意力稀释（Attention Dilution）**：Transformer 通过 softmax 归一化后的 attention 权重分配信息。随着序列长度增长，attention 分数被越来越多 token 分摊，每个 token 分到的注意力权重降低。关键信息（如问题前提、早期步骤的中间结果）被淹没在长序列中，模型无法有效聚焦。

2. **关键信息遗忘**：Transformer 虽然理论上可以通过 attention 访问任意位置，但在实践中，长距离位置的 attention 权重往往被大量中间 token 摊薄。推理链早期建立的关键前提或中间变量，在几百个 token 后被"遗忘"，导致后续推理基于错误或不完整的信息。

3. **恶性修正循环**：当 CoT 过长时，模型可能在中期步骤发现先前推理的错误，尝试回头修正。但由于 attention 已被稀释，修正过程可能引入新的错误，触发新的修正需要，形成"反复修改却无法收敛"的恶性循环。这本质上是因为模型失去了对原始问题约束的清晰"记忆"。

**一个量化直觉**：如果你的模型有效上下文窗口是 4096 token，CoT 从 500 增长到 2000，attention 散度增加 4 倍，但模型的"工作记忆"容量并未改变——能同时追踪的逻辑约束数量是有限的。

</details>

**(a) DTR 区分浅层 vs 深层 token 的机制**：

DTR 通过追踪 **Transformer 逐层预测分布的变化** 来区分 token 类型：

1. **记录预测分布**：对每个生成的 token，记录它在经过 Transformer 每一层处理后的预测分布（即从该层的 hidden state 投影到 vocab space 得到的概率分布）
2. **计算分布差异**：对相邻层的预测分布计算 **Jensen-Shannon 散度**（JS 散度），JS 散度越大说明该层对预测结果产生了显著改变
3. **判断收敛层**：
   - 浅层 token：JS 散度在早期层（如前 6 层）已接近 0 → 预测在浅层已稳定，后续层未改变
   - Deep-Thinking Token：JS 散度在深层（如 20+ 层）才接近 0 → 预测在深层仍在调整

**(b) 第二个模型（200 token, DTR 35%）推理更可靠**：

计算：500 × 10% = 50 vs 200 × 35% = 70 Deep-Thinking Token。第二个模型深层计算的 token 数量更多（70 > 50），根据 DTR 论文的实验结论（DTR 与准确率正相关），更可能产生正确的推理结果。
