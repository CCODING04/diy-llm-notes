### VC 维理论 + 泛化误差上界公式（豆包辅助整理）

#### 核心定义

**VC 维（Vapnik-Chervonenkis Dimension，记为 d）**：衡量**模型假设空间复杂度、拟合能力上限**的指标。

数学定义：模型能够**最多打散**的样本点数量。
- 打散：模型可以对样本做**任意二分类**，完美区分所有标签组合。

大白话：**VC 维越大，模型越复杂，拟合/记忆能力越强**。

#### 核心定理公式

$$ \epsilon(\hat{h}) \le \epsilon(h^*) + \mathcal{O}\left(\sqrt{\frac{d}{m}}\right) $$

**符号拆解**：
1. $\epsilon(\hat{h})$：学习得到的模型 $\hat{h}$ 的真实泛化误差（unseen 样本上的错误率）
2. $\epsilon(h^*)$：假设空间内理论最优模型 $h^*$ 的固有误差（模型能力上限，欠拟合部分）
3. $d$：假设空间的 VC 维（模型复杂度）
4. $m$：训练样本数量
5. $\mathcal{O}\left(\sqrt{\frac{d}{m}}\right)$：泛化差距上界、过拟合惩罚项，是 VC 维理论严格推导结果

**公式含义**：
> 训练出的模型真实误差 ≤ 模型能达到的最小固有误差 + 由 VC 维和样本量共同决定的过拟合风险

简化比例关系：$\text{泛化差距} \propto \sqrt{\frac{d}{m}}$

#### 核心逻辑链

1. **VC 维 d 过小**：模型太简单，$\epsilon(h^*)$ 很大 → **欠拟合**
2. **VC 维 d 过大，样本量 m 不足**：$\sqrt{d/m}$ 变大，过拟合惩罚项飙升 → **过拟合**
3. **VC 维与样本量匹配**：两项平衡，既能学到规律，又抑制噪声 → **最佳泛化**
4. **样本量 m 极大**：$\sqrt{d/m}$ 趋近于 0，高 VC 维复杂模型也能有效训练

#### 降低过拟合的 2 种方法

本质：**降低模型有效 VC 维 d，减小 $\sqrt{d/m}$**
1. 直接换 VC 维更低、结构更简单的模型（神经网络 → 逻辑回归）
2. 约束模型复杂度：L1/L2 正则化、Dropout、早停，间接压低有效 VC 维

#### 现实例子

- 逻辑回归：VC 维低，$\sqrt{d/m}$ 小，小数据稳定，不易过拟合
- 深度神经网络：VC 维极高，大数据 m 充足时泛化好；小数据集极易过拟合

#### ⚠️ 重要补充（导师备注）

现代神经网络的 VC 维通常**远大于**训练样本量（d >> m），按 VC 理论应严重过拟合，但实际泛化很好。这说明 VC 理论给出的上界**过于宽松（loose）**，不能完全解释深度学习的泛化现象。这也是为什么 Scaling Laws 研究用**经验性幂律**（α ≈ 0.1-0.3），而不是 VC 理论的 $1/\sqrt{m}$（α = 0.5）。课程中 9.2.1 节提到"这些是理论上的最坏情况上界，往往过于悲观"，指的就是这个问题。

### 均值估计公式推导与数学期望（豆包辅助整理）

#### 什么是数学期望 $\mathbb{E}[\cdot]$

**通俗理解**：一件事反复做无数次，最后稳定下来的平均结果。

例：抛公平硬币（正面=1分，反面=0分），抛 10000 次后平均值稳定在 0.5：
$$\mathbb{E}[\text{抛硬币得分}] = 0.5$$

**严格定义（离散型）**：每个结果 × 它出现的概率，全部加起来：
$$\mathbb{E}[X] = x_1 p_1 + x_2 p_2 + \dots$$

对于正态分布 $x_i \sim N(\mu, \sigma^2)$，期望就是总体真实均值 $\mu$：
$$\mathbb{E}[x_i] = \mu$$

**两个关键性质**：
1. 线性性：$\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]$（不管变量是否独立）
2. 常数的期望是自己：$\mathbb{E}[\mu] = \mu$

#### 均值估计 MSE 公式推导

已知 $x_1, x_2, \dots, x_n \sim N(\mu, \sigma^2)$ 独立同分布，$\hat{\mu} = \frac{1}{n}\sum_{i=1}^n x_i$，证明：

$$\mathbb{E}[(\hat{\mu} - \mu)^2] = \frac{\sigma^2}{n}$$

**第一步：转化为方差**

先求 $\hat{\mu}$ 的期望：
$$\mathbb{E}[\hat{\mu}] = \mathbb{E}\left[\frac{1}{n}\sum x_i\right] = \frac{1}{n} \cdot n\mu = \mu$$

样本均值是**无偏估计**，所以：
$$\mathbb{E}[(\hat{\mu} - \mu)^2] = \mathbb{E}[(\hat{\mu} - \mathbb{E}[\hat{\mu}])^2] = \mathrm{Var}(\hat{\mu})$$

**第二步：计算方差**

用两条性质：① $\mathrm{Var}(aY) = a^2 \mathrm{Var}(Y)$；② 独立变量方差可加：

$$\mathrm{Var}(\hat{\mu}) = \mathrm{Var}\left(\frac{1}{n}\sum x_i\right) = \frac{1}{n^2} \sum \mathrm{Var}(x_i) = \frac{1}{n^2} \cdot n\sigma^2 = \frac{\sigma^2}{n}$$

**结论**：
$$\mathbb{E}[(\hat{\mu} - \mu)^2] = \frac{\sigma^2}{n} = \sigma^2 \cdot n^{-1}$$

**通俗理解**：
1. 总体波动越大（$\sigma^2$ 越大），估计的平均误差越大
2. 样本量 $n$ 越大，平均误差越小（误差与 $n$ 成反比）
3. 这就是统计学核心规律：**样本越多，均值估计越准**

### μP 课下笔记（豆包辅助整理）

#### 核心问题

模型参数量放大 $r$ 倍时，传统训练方式下最优学习率必须跟着变小，否则训练不稳定。每放大一次模型就要重新暴力搜索学习率，算力成本极高。

**μP 的目标**：模型无论放大多少倍，最优学习率完全不变，直接复用小模型调好的超参。

#### 缩放规则表格（6 行）

| 超参 | matrix-like（注意力/FFN 权重） | others（Bias/LayerNorm 等） |
|------|------|------|
| AdamW 学习率 | $l \to l/r$ | 保持 $l$ 不变 |
| 初始化方差 | $\sigma \to \sigma/r$ | 保持 $\sigma$ 不变 |
| 输出层缩放因子 | $\tau \to \tau/r$ | 保持 $\tau$ 不变 |

符号说明：$M$ = 原始小模型超参，$M' \sim r$ = 放大 $r$ 倍后的大模型超参。

#### 逐行解读

**第 1 行：AdamW 学习率（矩阵类核心权重）**
- 矩阵类权重放大，**梯度会同步变大**，学习率除以 $r$ 抵消梯度变大的影响

**第 2 行：AdamW 学习率（其他参数）**
- 偏置、Norm 层等参数不受模型宽度影响，学习率不用缩放

**第 3 行：初始化方差（矩阵类核心权重）**
- 模型变宽，输入维度变大，初始化方差缩小保证前向传播方差稳定（和 Xavier 初始化逻辑一致）

**第 4 行：初始化方差（其他参数）**
- 非矩阵类参数维度不变，初始化不用改

**第 5 行：输出层缩放因子**
- 输出层梯度受模型宽度影响，同步缩放

**第 6 行：其他缩放因子**
- 大小模型保持不变

#### 核心原理

传统方法：模型放大 → 梯度暴涨 → 必须手动调小学习率，最优学习率漂移

μP 方法：**提前对学习率、初始化、输出层做反向缩放**
- 模型放大 $r$ 倍，梯度天然变大 $r$ 倍
- 学习率除以 $r$，刚好抵消梯度变化
- → 最终参数每一步的更新幅度完全不变
- → 最优学习率、超参，小模型调好直接照搬给大模型

**类比**：练投篮——小篮筐用力 $l$ 刚好投进；篮筐变大 $r$ 倍，μP 自动把用力除以 $r$，每次用力大小不变，投篮效果一致。

#### 工程价值

1. **超参可迁移**：小模型调好的学习率、batch size、权重衰减，直接用于千亿级大模型
2. **训练稳定性强**：从底层控制梯度更新幅度，模型放大不发散
3. **完美适配 Transformer**：专门针对注意力、FFN 核心矩阵权重设计
4. **与临界 Batch Size 互补**：μP 管学习率，临界 Batch Size 管批次大小，两者结合 = 完整大模型调参体系

### 联合缩放外推（Scaling Extrapolation）课下笔记（豆包辅助整理）

![联合缩放](<../images/9-28-参数_计算_数据的联合缩放.png>)

#### 核心思想

**只用极小的模型 + 少量数据，拟合出 Loss/准确率的幂律缩放公式，直接外推预测大得多的模型效果，不用花钱训练大模型。**

#### 左图 (a) 符号详解

**横轴：`data fraction: log₂(n/N)`**
- $N$：全集总数据量（最大规模的完整数据集）
- $n$：实际用来训练模型的样本量（人为使用的子集）
- $n/N$：数据占比
- $\log_2(n/N)$：对数尺度压缩，方便观察幂律缩放
- 例：$n/N = 1/8 \to \log_2(1/8) = -3$；$n/N = 1/16 \to \log_2(1/16) = -4$
- 越往左数据量越小，越往右越接近完整数据集

**纵轴：`model fraction: log₂(m/M)`**
- $M$：目标超大模型的总参数量（最终要外推预测的大模型）
- $m$：当前实际训练的小模型参数量
- $m/M$：模型规模占比
- $\log_2(m/M)$：对数尺度
- 例：$m/M = 1/16 \to \log_2(1/16) = -4$；$m/M = 1/4 \to \log_2(1/4) = -2$
- 越往下模型越小，越往上模型越大

**圆点含义**：
- **绿色圆点（fit）**：左下区域，$m = 1/16M$、$n = 1/8N$，只用小模型 + 少量数据拟合规律
- **红色圆点（extrapolated）**：右上区域，更大 $m$、$n$，纯靠小模型预测的超大模型
- 白色空心圆：完全不用的实验区间

#### 中图 (b)：ImageNet 图像分类实证

- 绿色点（fit）：只用 1/16 大小的小模型、1/8 的训练数据做实验拟合缩放规律
- 红色点（extrapolated）：用拟合出的规律，预测更大模型的 Top-1 错误率
- 横轴 = 实测错误率，纵轴 = 预测错误率
- 蓝色对角线：预测值 = 真实值（完美预测）
- 红色点紧贴对角线 → 预测极度精准
- 指标：$\mu = -4.5\%$（平均偏差极小），$\sigma = 4.681\%$（标准差小，稳定性强）

#### 右图 (c)：WikiText-103 语言建模实证

- 同样只用 1/16 小模型、1/8 数据拟合
- 红色外推点紧贴对角线 → 预测超大模型测试 Loss 极度准确
- 指标：$\mu = 0.5\%$（平均偏差几乎为 0），$\sigma = 1.689\%$（比图像任务更小，语言模型缩放规律更稳定）

#### 为什么用 log₂？

大模型缩放是幂律关系：$\text{Loss} \propto N^{-\alpha}$，$\text{Loss} \propto M^{-\beta}$。两边取对数后幂律变线性，更容易拟合和外推。用 $\log_2$ 是因为大模型习惯按 2 倍、4 倍、8 倍扩大规模，以 2 为底最直观。

#### 与之前知识的串联

- **μP**：保证学习率、更新规则随模型规模线性缩放 → 小模型的对数缩放规律可完美外推到大模型
- **临界 Batch Size**：同样用对数坐标观察幂律缩放，数学逻辑完全一致
- **联合缩放图**：告诉我们大模型该配多少参数、多少数据；μP 告诉我们学习率怎么随模型缩放；临界 Batch Size 告诉我们训练时 Batch Size 怎么动态调。**以上所有，只用小模型就能提前全部算出来**

<details>
<summary>📖 Q3 参考答案</summary>

**模型变宽时发生了什么**：

矩阵乘法 $y = Wx$，其中 $W \in \mathbb{R}^{rd \times d}$（宽度扩大 r 倍）。前向传播时：
$$y_i = \sum_{j=1}^{rd} W_{ij} x_j$$

求和项从 $d$ 个变为 $rd$ 个，**信号量（方差）天然增大 r 倍**。反向传播时梯度同样增大 r 倍。

**如果不调整学习率**：
- 梯度增大 r 倍 → 参数更新 Δθ = lr × gradient 也增大 r 倍
- 更新步长过大 → 训练不稳定、发散

**μP 的解决方案**：
- 学习率除以 r：lr' = lr/r
- 更新幅度：Δθ' = (lr/r) × (r × gradient) = lr × gradient → **与小模型完全相同**
- 初始化方差也除以 r：保持前向传播方差稳定（Xavier 思想）

**类比**：投篮时篮筐变大 r 倍（模型变宽），力量也天然变大 r 倍（梯度增长）。μP 自动把力量除以 r，保证每次投篮用力不变。
</details>

### 数据量对学习率的影响 — 课下笔记（豆包辅助整理 + 导师纠正）

#### 核心问题

数据量会不会影响最优学习率？怎么影响？和 μP 的关系是什么？

#### 核心结论

1. **模型变大 → 学习率要变小**（μP 自动搞定）
2. **数据变多 → 学习率可以变大**（μP 不管，需要手动调）
3. **数据越少，最优学习率越小，越容易过拟合**

#### 底层原理

**两个核心变量**：
- 数据量 $D$：总训练 Token 数
- Batch Size $B$：每次迭代的 Token 数
- 总迭代步数 $T = D / B$

**梯度噪声逻辑**：
- 数据越少 → 梯度噪声越大 → 模型容易过拟合、震荡 → 必须用更小的学习率
- 数据越多 → 梯度噪声越小 → 可以用更大学习率，大步快速收敛

#### ⚠️ 纠正：线性缩放 vs 平方根缩放

豆包原文混淆了两个不同的缩放规则：

- **线性缩放规则**（Goyal et al., 2017，**不是 OpenAI**）：Batch Size 扩大 $k$ 倍 → 学习率扩大 $k$ 倍。适用于 SGD + warmup 场景
- **平方根缩放规则**（某些理论分析）：lr ∝ √B，更保守

两者适用场景不同，不能混为一谈。

#### ⚠️ 纠正："lr ∝ 1/√数据量"不准确

数据量对学习率的影响是**间接的**，不存在 lr ∝ 1/√D 这样的直接数学关系。更准确的逻辑链：

```
数据量增加
  → 临界 batch size 变大（模块 2 已学）
  → 可以使用更大 batch
  → 按缩放规则（线性或平方根），lr 可以更大
```

中间经过了 **batch size** 这个中介变量，不是数据量直接影响 lr。

#### μP 与数据量的关系

| 变量变化 | 对最优学习率的影响 | μP 怎么处理 |
|---------|-------------------|------------|
| 模型宽度变大 $r$ 倍 | 学习率必须 ÷ $r$ | μP 自动缩放 |
| 数据量变多 | 学习率可以变大 | **μP 不处理**，需手动调整 |

μP 只解决"模型变大导致学习率漂移"的问题，数据量引起的学习率变化需要通过其他方式处理。

#### 实操规律

| 场景 | 学习率策略 |
|------|-----------|
| 数据少（<4 epochs，重复训练） | 梯度噪声大、易过拟合，最优 lr 显著变小 |
| 数据充足（>10 epochs） | 梯度稳定，μP 基础 lr 可直接用 |
| 极端重复（40+ epochs） | 收益归零，lr 必须压到极低否则发散 |

#### 与临界 Batch Size 联动

数据量增加 → 临界 Batch Size 变大 → Batch Size 变大 → 最优学习率按缩放规则同步变大

**三者联动体系：数据 ↑ → Batch ↑ → 学习率 ↑**

#### 小提问

> 如果我们用 μP 固定了模型缩放的学习率，现在训练数据减半，最优学习率应该变大还是变小？

**答案**：应该**变小**。原因：
1. 数据减半 → 梯度噪声增大（每个 batch 的采样方差更大）
2. 数据减半 → 过拟合风险增大
3. 两者都要求更小的学习率来保持训练稳定
4. 注意：μP 不会自动处理这个变化，需要手动下调

### 图 9-44 多领域缩放热力图详解（豆包辅助整理 + 导师验证）

#### 图表布局

3 行 6 子图，覆盖 5 类训练语料 + 全局平均：
- 上排（3 张线图）：Loss 随算力的缩放趋势
- 中排/下排（热力图）：参数量 × 算力的 Loss 等高线

统一坐标轴：
- 横轴：Non-embedding Parameters（非嵌入层参数量，10⁹）
- 纵轴：Compute（总算力，10¹⁸ FLOPs）
- 热力图颜色：红色 = Loss 高（效果差），蓝色 = Loss 低（效果好）

#### 热力图关键信息

**黑色等高线 + 散点**：等高线 = 相同 Loss 的参数-算力配比，散点 = 实际训练的模型。散点沿等高线分布 → 实验完全拟合缩放规律。

**拟合公式**（以全局平均为例）：

$$\text{Loss} = \frac{7.15 \times 10^{-2}}{N^{0.39}} + \frac{3.00 \times 10^{-1}}{D^{0.31}} + 0.31$$

- $N^{0.39}$：参数量贡献（指数 0.39）
- $D^{0.31}$：数据量贡献（指数 0.31）
- 参数量指数 > 数据量指数 → 参数量对效果的贡献略大于数据量
- $K^2 \approx 0.01$：拟合常数（来自最优比例公式 $N_{\text{opt}}/D_{\text{opt}} = K^2 \cdot (C/6)^{\eta}$），$K^2$ 越小说明最优策略越倾向于"多数据、少参数"。此处 $K^2 \approx 0.01$ 意味着约 100 tokens/param

#### 分领域 η 对比

| 领域 | $\eta$ | 含义 |
|------|--------|------|
| 代码 | -0.05 | 更吃模型，优先堆参数量 |
| 英文 | 中间 | 参数/数据均衡 |
| 中文 | -0.33 | 更吃数据，优先堆高质量中文数据 |

固定算力 $C = 10^{20}$ FLOPs 时：全局平均 $N_{\text{opt}} = 10^{10}$ 参数，$D_{\text{opt}} = 191.87B$ token。

#### 为什么代码 Loss 最低但代码任务最难？

这里的 Loss = NLL Loss（自回归预测损失），衡量"预测下一个 token 的难度"，**不是任务本身的难度**。

**代码**：语法严格（关键字、缩进、括号匹配），上下文约束极强，序列熵极低 → 单步预测容易 → NLL Loss 低。但代码需要几十步长程逻辑连贯，一步错步步错 → 全局任务极难。

**中文**：语法自由、歧义多，上下文约束弱，序列熵极高 → 单步预测困难 → NLL Loss 高。但日常中文长程逻辑简单 → 全局任务容易。

**一句话**：NLL Loss 衡量"下一个 token 好不好猜"，不是"任务好不好做"。

#### 与缩放知识的串联

1. 代码/英文/中文全部遵循幂律缩放
2. 代码吃模型（η 接近 0）、中文吃数据（η 最负）、英文均衡
3. K² 极小，小模型拟合的公式能精准预测超大模型
4. μP 可直接迁移超参，配合缩放律实现高效模型设计

**Q1 批改**：核心方向正确，但**机制描述不够精确**——缺少"一次训练、多次 Decay"的关键机制。 — 得分：**7/10**

- ✅ "Stable 阶段可共享"——方向正确
- ⚠️ 缺少关键机制：WSD 的核心不是"在 Stable 中找到位置再 Decay"，而是**一次完整的 Stable 阶段训练完成后，在不同 checkpoint 处插入短 Decay（约 5-10% 步数），模拟不同数据量的训练效果**。即 O(m+n) 而非 O(m×n)：m 个模型大小 × n 个数据量，传统方法需 m×n 次完整训练；WSD 只需训练 m 个模型各 1 次 Stable，再在 n 个 checkpoint 各做 1 次短 Decay → 总共 m+n 次

<details>
<summary>📖 Q1 参考答案</summary>

**WSD 三阶段**：
1. **Warmup**：学习率从 0 线性上升到峰值
2. **Stable**：学习率保持恒定，占训练的大部分时间（约 90% 步数）
3. **Decay**：学习率快速衰减到 0，占约 5-10% 步数

**为什么能降低成本**：

Cosine 调度器需要预先知道总步数，衰减曲线贯穿整个训练。想评估"训练到 40N tokens"的效果，必须从头跑一次完整训练。

WSD 的 Stable 阶段共享机制：
- 训练 1 个模型，跑完完整 Stable 阶段（如 80N 步）
- 在 40N 步 checkpoint 处插入 4N 步 Decay → 得到 40N tokens 的性能
- 在 60N 步 checkpoint 处插入 6N 步 Decay → 得到 60N tokens 的性能
- **一次训练，多个数据点**

传统 Cosine：m 个模型大小 × n 个数据量 = **O(m×n) 次完整训练**
WSD：m 个模型各 1 次 Stable + n 个 checkpoint 各 1 次短 Decay = **O(m+n) 次**
</details>

<summary>📖 Q3 参考答案</summary>

**最优策略：μP + WSD 组合（MiniCPM 路线）**

**为什么不选纯经验拟合（DeepSeek 路线）**：
- 经验拟合需要为**每个计算预算**做 bs/lr 扫描 → GPU 需求大
- 没有大量 GPU 时，扫描实验不可行

**为什么不选纯 μP**：
- μP 只解决"模型变宽时学习率怎么调"，不解决"不同数据量怎么分配"
- 需要配合其他方法做 Chinchilla 分析

**μP + WSD 组合的优势**：
```
μP 解决的问题：
  → 小模型调一次超参（lr, init_std, scale_emb）
  → 直接迁移到所有规模
  → 省去每个规模的超参搜索（节省 GPU）

WSD 解决的问题：
  → 一次训练，多个数据点
  → 在不同 checkpoint 插入 Decay
  → 省去每个数据量的完整训练（节省 GPU）

总成本：O(m+n)，其中：
  m = 模型规模数（如 40M, 100M, 300M, 1B）
  n = 数据量采样点数（如 10N, 20N, 40N, 80N tokens）
```

**具体执行步骤**：
1. 用 μP 在最小模型（40M）上搜索超参 → 确定 η_base, σ_base, m_emb
2. 用 μP 迁移规则，将超参迁移到 100M, 300M, 1B 规模
3. 每个规模用 WSD 训练：跑完 Stable 阶段 → 在不同 checkpoint 插入 Decay
4. 拟合 $L(N, D) = E + AN^{-\alpha} + BD^{-\beta}$ → 外推预测目标规模
5. 选择最优 (N, D) 组合 → 训练最终模型

**关键洞察**：μP 和 WSD 不是二选一的关系，而是**互补**的——μP 管"模型宽度维度"的超参迁移，WSD 管"数据量维度"的高效分析。两者结合 = 用最少 GPU 覆盖最多的 (N, D) 组合。
