## 核心内容

### 一、为何关注缩放定律？

想象一个场景：你拥有一个月内使用 10 万台 H100 GPU 的权限，目标是构建一个顶尖的开源语言模型。面对如此庞大的资源，你需要做出一系列关键决策：

- **基础设施**：搭建分布式训练框架（第 8 章已学）
- **数据**：构建一个高质量的预训练数据集
- **模型**：选择架构、超参数，并决定模型规模和训练时长

传统的深度学习范式是通过大量昂贵的实验来调整超参数，这在 LLM 时代不可行。**缩放定律提供了一种替代方案**：在小规模上进行实验，建立性能与规模（数据、模型、计算）之间的可预测关系，然后将这些规律外推到大规模。

核心价值：**用 1% 的算力，预测 100% 规模的性能**。

### 二、缩放定律的历史与背景

#### 2.1 理论起源：样本复杂度

在统计学习理论中，**样本复杂度（Sample Complexity）** 描述了要达到一定的学习效果需要多少样本。VC 维理论给出了泛化误差的上界：

$$ \epsilon(\hat{h}) \le \epsilon(h^*) + \mathcal{O}\left(\sqrt{\frac{d}{m}}\right) $$

这本质上是一个理论版的缩放定律：误差随样本量 $m$ 的增加以 $1/\sqrt{m}$ 的速率下降。但这些是**理论上的最坏情况上界**，往往过于悲观。

> 📎 **来源追溯**：VC 维理论来自 Vapnik & Chervonenkis (1971)。更详细的讨论可参考 [CMU 课程讲义](https://www.cs.cmu.edu/~epxing/Class/10701/slides/lecture16-VC.pdf)。

#### 2.2 早期实证研究

**贝尔实验室（NeurIPS 1993）**：最早的（数据）缩放定律研究。发现分类器的测试误差随训练集大小增加呈**幂律衰减**，并提出可以通过在小数据集上拟合学习曲线来预测大数据集上的性能。

![早期贝尔实验室研究](<../images/9-1-引用贝尔实验室论文.png>)

![训练数据与损失](<../images/9-1-训练数据与损失.png>)

**Banko & Brill（ACL 2001）**：经典的 NLP 论文，指出在某些任务上，**增加数据量带来的性能提升远超改进算法本身**。提出了一个重要观点：我们应该权衡"花钱做算法研发"和"花钱做数据收集"的投入。

![混淆集消歧任务学习曲线](<../images/9-2-混淆集消歧任务上的学习曲线.png>)

**Kolachina et al.（ACL 2012）**：验证了数据量与模型性能之间存在可预测的数学关系。用 Moses 统计机器翻译系统在 30 种语言对上实验，发现**幂律（Power Law）拟合效果最好**，且即使没有平行语料，也能粗略预测学习曲线形状。

![曲线拟合](<../images/9-3-使用不同的曲线簇对测试数据集进行曲线拟合.png>)

![曲线簇](<../images/9-3-曲线簇.png>)

**Hestness et al.（2017）**：最早的大规模神经网络缩放定律研究。发现机器翻译、语言建模、语音识别等多个任务中，性能都遵循可预测的幂律关系。提出了著名的**"三阶段"学习曲线**：

![幂律学习曲线](<../images/9-4-幂律学习曲线示意图.png>)

```
三阶段学习曲线（Hestness 2017）：

  ① 小数据区（Small Data Region）
    → 数据太少，性能接近随机猜测
    → 增加少量数据几乎没有帮助

  ② 幂律区（Power-law Region）
    → 性能随数据量增加稳定提升
    → 在 log-log 坐标下呈线性
    → 这是 Scaling Laws 研究的核心区域

  ③ 不可约误差区（Irreducible Error Region）
    → 数据量足够大，性能达到瓶颈
    → 受限于模型容量或任务固有难度
```

![Hestness 关键概念](<../images/9-5-Hestness（2017）提出的关键概念.png>)

> 📎 **来源追溯**：Hestness et al., *Deep Learning Scaling is Predictable, Empirically* (arXiv:1712.00409)。这篇论文极具前瞻性，已经预示了"涌现"、"计算缩放"和"性能-精度权衡"等现代 LLM 领域的关键概念。

### 四、数据量 vs. 性能：幂律关系

#### 4.1 什么是幂律？

一个经验性观察：在 x 轴绘制数据集大小（token 数量），y 轴绘制测试损失（Loss），在**双对数坐标系（log-log plot）** 上呈现线性关系。

双对数图上的直线意味着两个变量之间存在**幂律（Power Law）** 关系：

$$ \text{Error} = C \cdot n^{-\alpha} $$

其中 $C$ 是常数（截距），$\alpha$ 是缩放指数（斜率），$n$ 是数据量。

![数据-误差幂律关系](<../images/9-9-数据大小与模型误差之间的幂律关系.png>)

#### 4.2 为什么是幂律？— 理论直觉

**示例 1：均值估计**

假设数据点 $x_1, ..., x_n$ 服从 $N(\mu, \sigma^2)$，用样本均值 $\hat{\mu} = \frac{\sum x_i}{n}$ 估计真实均值 $\mu$：

$$ \mathbb{E}[(\hat{\mu} - \mu)^2] = \frac{\sigma^2}{n} = \sigma^2 \cdot n^{-1} $$

取对数：$\log(\text{Error}) = -\log(n) + 2\log(\sigma)$

在 log-log 坐标下是斜率为 $-1$ 的直线。这是最简单的幂律示例。

**示例 2：2D 预测任务（非参数学习）**

在 2D 平面上均匀撒 $n$ 个点，用"切格子"方法预测目标函数：
- 最优边长 = $n^{-1/4}$（偏差-方差权衡的平衡点）
- 面积 = $(n^{-1/4})^2 = n^{-1/2}$
- 每个格子平均样本数 = $n / \sqrt{n} = \sqrt{n}$
- 误差 $\approx 1/\sqrt{n} = n^{-1/2}$

推广到 $d$ 维空间：

$$ \text{Error} = n^{-1/d} $$

**关键洞察**：缩放指数 $\alpha = 1/d$ 反映了数据流形的**内在维度**。指数越小，任务内在维度越高，学习难度越大。

#### 4.3 神经网络的缩放指数

经典统计模型（如线性回归）的误差衰减速率是 $1/n$（$\alpha=1$）。但神经网络的缩放指数小得多：

```
任务              缩放指数 α
──────────────────────────
机器翻译          -0.13
语音识别          -0.3
语言模型          -0.095
```

这比经典统计模型慢得多。原因是神经网络是**非参数模型**，可以拟合任意复杂函数。对于 $d$ 维空间中的非参数学习问题，误差衰减速率近似为 $n^{-1/d}$。$\alpha$ 越小，说明任务的内在维度越高。

![不同任务的缩放指数](<../images/9-10-三种不同任务的缩放指数.png>)

> 📎 **来源追溯**：内在维度与缩放指数的关系来自 Bahri et al. (2021), *Explaining Neural Scaling Laws* (arXiv:2102.06701)。

![维度与斜率关系](<../images/9-11-维度与scaling laws斜率之间的关系.png>)

图中粉色点（Teacher-Student，合成数据）完美落在直线上，证明理论控制实验中缩放指数严格由维度决定。其他颜色点（CIFAR-10、MNIST 等真实数据）也大致排列在直线上，但内在维度的估计方法误差较大，结论并非无懈可击。

### 五、数据组成与数据重复

#### 5.1 数据组成：影响截距，不影响斜率

OpenAI 原论文发现：数据集的组成只影响偏移量（$y = kx + b$ 中的 $b$），不影响斜率。这意味着**数据选择实验可以在小模型上进行**，结果可外推到大模型。

![数据组成影响偏移量](<../images/9-12-数据组成只影响偏移量.png>)

Hashimoto (2021) 系统研究了数据混合比例的影响：

![数据混合比例影响](<../images/9-13-数据混合比例如何影响缩放定律.png>)

```
关键发现：
  - 不同混合比例 q 的曲线斜率相同 → 学习速率不变
  - 但截距不同 → 更好的数据配比能降低误差
  - 混合两种数据源（q ≈ 0.5）时误差最低 → 多样性有益
```

> 📎 **来源追溯**：Hashimoto et al., *Model Performance Scaling with Multiple Data Sources* (ICML 2021)。

#### 5.2 重复数据：收益递减

实际训练中数据量有限。如果重复数据（增加 Epochs），性能还能像新数据那样持续提升吗？

![重复数据收益递减](<../images/9-14-重复数据与新数据对模型性能的影响.png>)

```
重复数据的三个阶段：
  - ≤ 4 个 Epoch：实线和虚线几乎重合 → 重复效果 ≈ 新数据
  - 4-40 个 Epoch：实线偏离虚线 → 收益迅速递减
  - ≥ 40 个 Epoch：实线变平 → 重复数据变得毫无价值
```

**有效数据量公式**：

$$ D' = U_D + U_D R_D^* (1 - e^{\frac{-R_D}{R_D^*}}) $$

- $D'$：有效数据量（模型感觉自己学到了多少）
- $U_D$：唯一数据量（原始数据集大小）
- $R_D$：重复次数（Epochs）
- $R_D^*$：饱和常数

第二项是典型的**饱和函数**：随重复次数增加趋向常数上限。无论重复多少次，有效数据量都有天花板。

> 📎 **来源追溯**：*Scaling Data-Constrained Language Models* (arXiv:2305.16264)。

#### 5.3 数据选择策略随规模变化

![大数据下的数据选择策略](<../images/9-15-大数据下的数据选择策略.png>)

```
数据选择策略的规模依赖性：
  - 小模型/小规模训练：只用最高质量数据（哪怕量少）
  - 大模型/大规模训练：放宽标准，新数据比质量更重要
    → 因为在大规模下，"还凑合"的新数据 > 重复的高质量数据
```

<summary>📖 Q1 参考答案</summary>

**为什么是直线（均值估计解释）**：

均值估计的 MSE = σ²/n = σ²·n^(-1)。两边取对数：
$$\log(\text{Error}) = -1 \cdot \log(n) + 2\log(\sigma)$$

这是 log-log 坐标下的直线方程 y = kx + b，斜率 k = -1。所以幂律关系在双对数图上天然表现为直线。

**数值计算**（α = 0.1，数据量增加 10 倍）：
$$\frac{\text{Loss}_{new}}{\text{Loss}_{old}} = \frac{(10n)^{-0.1}}{n^{-0.1}} = 10^{-0.1} \approx 0.794$$

误差下降约 **20.6%**。注意：α = 0.1 意味着缩放效率很低（语言模型 α ≈ 0.095），数据量增加 10 倍只能带来约 20% 的改善。

<summary>📖 Q2 参考答案</summary>

**区别**：
- 数据量（n）→ 影响斜率项 α·log(n) → 决定"学习速率"，即 loss 随数据增长下降的快慢

**为什么在小模型上做实验**：

因为不同数据组成的缩放曲线**斜率相同、截距不同**（平行线）。平行线的相对高低在任何 x 值都保持一致。所以：
- 在 100M 模型上，数据源 A 的 loss 比数据源 B 低 → 两条平行线 A 在下
- 在 70B 模型上，A 仍然比 B 低 → 平行线不会交叉

因此可以在小模型上做数据选择实验，节省算力，结果可外推到大模型。
